# Week 05 Lab: Nesting & Cascade Layers

This lab demonstrates how to organize CSS using **Cascade Layers (`@layer`)** and **native CSS Nesting**. The page includes global styles and an interactive flight booking card with component-specific styling.

## Features

* Uses `@layer reset, base, components` to control style precedence
* Uses native CSS nesting to scope booking card styles
* Demonstrates component-specific `.btn` styling without `!important`
* Includes hover, active, and focus states
* Keeps component styles organized and isolated
